# YumRoute

YumRoute is a food ordering and management web application built with **Spring Boot, Thymeleaf, and MySQL**. It provides a simple platform for managing customers, inventory, and orders with secure authentication and role-based access control.

## Features

- User Registration & Login
- Admin and Staff Role-Based Access
- Customer Management
- Inventory Management
- Order Management
- MySQL Database Integration
- Secure Authentication
- Thymeleaf-based User Interface

## Technologies Stack

- Backend: Spring Boot, Java 8, Spring MVC, Spring Data JPA (Hibernate)
- Frontend: Thymeleaf, HTML, CSS, JavaScript
- Database: MySQL
- IDE: Eclipse, Spring Tool Suite (STS)

## Prerequisites
Before running this project, ensure you have the following installed:
- Java 8
- MySQL
- Maven
- Eclipse or Spring Tool Suite (STS)
